# Методология исследования

## Общая цель

Проверить гипотезу об упругом пространстве-времени через анализ кривых вращения галактик из базы SPARC.

## Этап 1. Базовая проверка модели (одна галактика)

- Загружаем данные для NGC 3198
- Подгоняем модель $v(r) = \sqrt{v_{\text{visible}}^2(r) + v_0^2}$
- Проверяем постоянство $v_0$ внутри галактики
- Критерий успеха: $\chi^2/N_{\text{dof}} < 2$

## Этап 2. Расширение на множество галактик

- 20-30 галактик из SPARC
- Для каждой находим $v_0$
- Критерий успеха: 80% галактик с $\chi^2/N_{\text{dof}} < 2$

## Этап 3. Проверка BTFR

- График: $\log(v_0^4)$ vs $\log(M_b)$
- Критерий успеха: $\alpha = 1 \pm 0.15$, $R^2 > 0.85$

## Этап 4. Сравнение с моделью тёмной материи

- Подгоняем изотермическое гало ТМ
- Сравниваем по BIC
- Критерий успеха: $\Delta\text{BIC} > 0$

## Этап 5. Уникальные предсказания

- Гистерезис при слияниях
- Зависимость от возраста
- Смещение провиса (линзирование)
