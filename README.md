# Elastic Spacetime Model (REM-модель)

##  Цель проекта

Проверка гипотезы об упругом пространстве-времени как альтернативы гипотезе тёмной материи через анализ кривых вращения галактик.

##  Основная идея

Пространство-время рассматривается как вязкоупругая среда с памятью. Под действием массы галактики оно испытывает остаточную деформацию ("провис"), которая создаёт дополнительный гравитационный потенциал:

$$\Phi_{\text{eff}}(r) = -\frac{GM(r)}{r} + v_0^2 \ln\left(\frac{r}{r_0}\right)$$

Это приводит к модифицированной кривой вращения:

$$v(r) = \sqrt{v_{\text{visible}}^2(r) + v_0^2}$$

где $v_0$ — характеристическая скорость упругого провиса.

##  Методология

1. **Этап 1:** Проверка модели на одной галактике (NGC 3198)
2. **Этап 2:** Расширение на 20-30 галактик из SPARC
3. **Этап 3:** Проверка барионного соотношения Талли-Фишера (BTFR)
4. **Этап 4:** Сравнение с моделью тёмной материи (критерий BIC)
5. **Этап 5:** Проверка уникальных предсказаний:
   - Гистерезис при слияниях галактик
   - Зависимость $v_0$ от возраста галактики
   - Смещение провиса (гравитационное линзирование)

Подробное описание — в `docs/methodology.md`.

##  Данные

Используется база **SPARC** (Spitzer Photometry and Accurate Rotation Curves):
- Lelli F., McGaugh S., Schombert J., AJ 152, 157 (2016)
- Скачать: http://astroweb.case.edu/data/sparc/

Данные помещаются в папку `data/raw/` (не включены в репозиторий из-за размера).

##  Установка

```bash
# Клонируем репозиторий
git clone https://github.com/ТВОЙ_ЛОГИН/elastic-spacetime.git
cd elastic-spacetime

# Создаём виртуальное окружение
python -m venv venv

# Активируем
# Windows PowerShell: venv\Scripts\Activate.ps1
# Linux/Mac: source venv/bin/activate

# Устанавливаем зависимости
pip install --upgrade pip
pip install -r requirements.txt
```
