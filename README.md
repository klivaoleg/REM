# Elastic Spacetime Model (REM-модель)

## Цель проекта

Проверка гипотезы об упругом пространстве-времени как альтернативы гипотезе тёмной материи через анализ кривых вращения галактик.

Научный проект для конференции "Большие вызовы" (2026).

## Основная идея

Пространство-время рассматривается как вязкоупругая среда с памятью. Под действием массы галактики оно испытывает остаточную деформацию ("провис"), которая создаёт дополнительный гравитационный потенциал:

$$\Phi_{\text{eff}}(r) = -\frac{GM(r)}{r} + v_0^2 \ln\left(\frac{r}{r_0}\right)$$

Это приводит к модифицированной кривой вращения с плавным переходом:

$$v^2(r) = v_{\text{visible}}^2(r) + v_0^2 \left(1 - e^{-r/r_t}\right)$$

где:
- $v_0$ — характеристическая скорость упругой деформации пространства-времени
- $r_t$ — радиус плавного перехода между ньютоновским и упругим режимами
- $v_{\text{visible}}^2(r) = v_{\text{gas}}^2 + v_{\text{disk}}^2 + v_{\text{bulge}}^2$ — вклад видимого вещества

## Методология

### Этап 1: Проверка модели на отдельных галактиках

1. **NGC 3198** (галактика с гипотезой Maximum Disk):
   - Однопараметрическая модель: $\chi^2/\nu = 133.48$
   - Модель отвергнута из-за систематического завышения скоростей в центре

2. **UGC 128** (LSB-галактика с дефицитом видимой массы):
   - Двухпараметрическая подгонка: $\chi^2/\nu = 3.42$
   - Параметры: $v_0 = 117.4 \pm 1.0$ км/с, $r_t = 9.95 \pm 0.59$ кпк
   - Отличное количественное согласие с данными

### Этап 2: Массовая проверка (в разработке)

- Автоматическая подгонка для 20-30 галактик
- Проверка соотношения Талли-Фишера: $v_0^4 \propto M_b$
- Сравнение с моделью тёмной материи (критерий BIC)

### Этап 3: Уникальные предсказания (планируется)

- Гистерезис при слияниях галактик
- Зависимость $v_0$ от возраста галактики
- Смещение центра провиса (гравитационное линзирование)

## Данные

Используется база **SPARC** (Spitzer Photometry and Accurate Rotation Curves):
- Lelli F., McGaugh S., Schombert J., AJ 152, 157 (2016)
- URL: https://astroweb.case.edu/SPARC/

Данные помещаются в папку `data/raw/SPARC/` (не включены в репозиторий из-за размера).
